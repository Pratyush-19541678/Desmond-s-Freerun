DESMON RUN

You are Desmond — the only runner in Monteriggioni.
You start atop the highest tower viewpoint. Walk, sprint, climb, hang from ledges and dive across the open rooftops.

W A S Dwalk (camera-relative)
Shift + movesprint · Q / E or double-tap A/D = feint · C = slide
Spacejump (tap = hop, hold = high)
On a wallWASD climb (≤12 m) · Space jump off
Hanging / AirW pull up · S drop · E dive
C / Zhold = crouch · toggle = prone crawl (tunnels)
Mouse / Rlook (click = lock) · respawn

Tip: sprint at a wall to climb it, fall past a ledge to hang, and dive from the tower into the hay bale for a leap of faith.
